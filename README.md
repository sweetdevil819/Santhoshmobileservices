# Doorstep Mobile Repair Services - Bhimavaram, AP
### Technician: Santhosh Kumar (Instagram: [@mobile_melodies](https://instagram.com/mobile_melodies))

A modern, responsive, full-featured web application for **Santhosh Kumar's Doorstep Mobile Repair Service** operating across Bhimavaram and surrounding areas in West Godavari District, Andhra Pradesh.

---

## 📱 Key Features

- **⚡ Instant Doorstep Booking System**: Interactive booking modal with device brand/model selector, problem description, time slots, and direct WhatsApp dispatch.
- **📍 Service Area Coverage Checker**: Live interactive locality and postal code validator for Bhimavaram (Balusumudi, Gunupudi, SRKR College Road, Chinna Amiram, DNR College Road, Gandhinagar, etc.) with estimated technician arrival times.
- **🛠️ 10 Detailed Repair Services**: Screen/display replacement, battery replacement, charging port repair, speaker/mic, camera, liquid damage repair, chip-level logic board diagnostics, and more.
- **⭐ Real Customer Reviews with Photo Uploads**: Real reviews from verified customers with optional photo upload (customers can upload pictures of their repaired phone or bill), persistent via browser local storage.
- **📞 Direct Contact Integrations**: One-tap phone calls (`7036945947`), pre-filled WhatsApp chat messages, and official Instagram link (`mobile_melodies`).
- **📱 Responsive Mobile-First Design**: Optimized for smartphones with a sticky quick-action bottom bar, smooth navigation drawer, and high-performance layout.

---

## 💻 Tech Stack

- **Frontend**: React 19, TypeScript, Tailwind CSS v4, Lucide Icons, Motion
- **Tooling & Bundler**: Vite 8
- **Backend**: Node.js, Express, TSX

## 🚀 Getting Started

### 1. Prerequisites
Ensure you have **Node.js (v20 or higher)** installed on your machine.

### 2. Installation
```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/mobile-repair-bhimavaram.git

# Navigate to project directory
cd mobile-repair-bhimavaram

# Install dependencies
npm install
```

### 3. Running Locally
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### 4. Build for Production
```bash
npm run build
```
